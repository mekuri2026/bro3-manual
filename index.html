はじめに ・ 3ステップで始める

ルート捲りは全体地図で使い、施設削除は都市画面で使います。まずはめくりを動かしてみましょう。

  1. 全体地図を開き、画面の ≡ ルート捲り を押してパネルを開く。
  2. 🔵 めくり の ①出す武将 で出兵拠点を選び 武将取得 → 使う武将に ☑（自動保存）。
  3. ②ルート で ルート作成: OFF を押して ON にし、地図のマスを順にクリック → ③開始。

どのセクションも、見出しの右に ①②③ と操作の順番が書いてあります。上から順に進めれば動くように並べてあります。

自己責任自動出兵は規約でBOT行為とみなされる可能性があります。BAN・規約リスクは利用者自身の責任で。長時間の無人放置ほどリスクは上がります。ツールは手動出兵と同じリクエストを送るだけで、検出回避はしません。
最初の一度だけ武将の選択は出兵に直結します。長く回す前に、少量で「意図した武将・拠点で出るか」を必ず確認してください（武将の排他参照）。スキル回復・領地統制・本拠地名リセット合図は、最初に1回だけ本物の操作を捕捉する準備が要ります（検証用参照）。

🔵 めくり（ルート捲り）

①武将 ②ルート ③開始

武将を1体ずつ出して、地図のマスを順に捲る（＝取得する）機能です。足場を伸ばすときや、囲いを作るときに使います。

手順

  1. ①出す武将：出兵拠点 を選ぶ（★は現在地。無ければ ↻ で全拠点を読み直し）。デッキ の番号を選び 武将取得 → 使う武将に ☑。複数☑なら順番に使います。☑は自動保存されます。🔒が付いた武将は、鹵獲やリングで使用中です。
  2. ②ルート：ルート作成: OFF を押して ON にし、地図のマスを順にクリックして経由地を置く。1つ戻す／クリア で直せます。経由地だけ残して途中のマスを捨てるなら、経由地以外を破棄。経由地ごとの破棄をまとめて付けるなら 全経由地の破棄を一括✓。
  3. ③開始：ルート確認(読むだけ) で、赤＝取得予定・黄＝等級超で止まる可能性・灰＝回避、を確かめてから 開始。止めるときは 停止（めくりだけが止まります）。

🔄 経由地のマスを破棄やり直し

経由地に置いたマスのうち、自分の領地になっているものを破棄し直します。1回目に押すと対象のマス数を表示し、もう一度押すと実行します（二度押し）。領地統制をセットしてから がONなら、先に領地統制をセットします。

リングと同時に動かせる（v8.60）めくりの経由地（青）とリングの輪（緑）は別々です。めくりで敵の本拠地へ向かいながらリングを設定・稼働させても、互いのルートや輪は変わりません。めくりの クリア はめくりだけ、リングの 輪を消す はリングだけを消します。めくりが動いている間にリングの出番が近づくと、パネルの一番上に赤い帯と［めくりを止める］が出て音が鳴ります（何分前かはめくりの⚙「リングの出番の◯分前に知らせる」。既定5分・0で知らせない）。
継続する画面を移動・リロードしても、前進中のめくりは自動で再開し、破棄予定のマスも漏れずに引き継がれます。経由地と☑した武将も復元されます。

💊 スキル回復

①読む ②回す ③戻す

回復中のスキルを持つカードをデッキに載せ、施術（スキル回復時間を短縮するスキル）を撃って一気に回復させる機能です。戦争中、敵の攻撃の合間に使う道具です。終わったら、ツールが載せたカードを自動で降ろします。

はじめに（最初に1回だけ・v8.94〜）

ゲームのカードのラベルは、番号の枠が決まっていて、名前を各自で付けています。どのラベルに何を入れているかは人によって違うので、最初にツールへ教えます。

  1. ラベルを分けておく：施術を撃つ側のカード（施術・吐息・聖水・湯薬など、スキル回復時間を短縮するカード）を1つのラベルに、神医の術式のカードを別の1つのラベルにまとめます。名前は何でも構いません（例：「無限回復」「神医」）。
  2. 0 初期設定：💊 スキル回復のいちばん上の 🔎 ラベルを読み込んで候補を出す を押します。ツールがラベルごとに1ページ目のカードを調べ、施術のカードが多いラベルを「無限回復(施術)」、術式のカードが多いラベルを「神医」の候補にします。候補が正しいか確かめ、違えば選び直して 保存 を押します。「回復」は、回復のカードを別のラベルに分けている人だけ選びます（任意）。保存するまで ♾ と 🎯 は始まりません。
  3. 神医の捕捉：🔬 検証用 の 💊 神医の使用を捕捉 をONにして、神医のカードを手で1回使います（拠点にセットしてスキルを使い、セットを解除する方法で）。捕捉するまで、ツールは神医の術式を使いません。HP が100に足りないカードがあると、その回は止まります。
  4. 施術のカードをデッキに載せる：♾ は施術のカードを自分では載せません。開始の前に、施術のカードをデッキに載せておきます（手で、またはゲームのデッキ一括UPで）。載っていないと「デッキに使える施術のカードがありません」と出て始まりません。施術のカードが載っている拠点が「作業拠点」になり、回復中のカードはその拠点のデッキに載せます。その拠点のデッキに空きを作っておいてください。

手順

  1. ①回復中のカードを読む：📥 回復中のカードを一覧(読むだけ) で、回復中のスキルを持つカードと残り時間を一覧します。読むファイルのグループは☑で選べます（全部ON／全部OFF。☑は保存されます）。カードは動きません。この☑は一覧を見るときだけのものです。♾ は☑に関係なく、全部のカードから回復中のものを探します。
  2. ②回す：次のどちらかを 開始。
    • ♾ 無限回復：残り10時間未満のスキルを全部回復させます（対象）。残り10時間以上のスキルは、枠が空いていれば一緒に載せ、撃つたびについでに縮みます（ついで）。種類（短縮系・湯薬・神医など）では選びません。
      ☑ 10時間以上のスキルも回復させる（v8.83〜）を付けると、残り10時間以上のスキル（強襲天奮迅33時間・湯薬66時間など）も対象にして、回復し終わるまで撃ちます。神医（術式・施術）と、弾のカード（無限回復・回復・神医のラベル）は除きます（v8.85〜）。
      撃った施術の実測（v8.91〜）：撃ったあと実際に縮んだ分数をカードごとに覚え、次からその分数で選びます。鏡（明鏡・継承）が付いたカードは、鏡の分も一緒に効くので大きく縮みます（例：施術LV10＋鏡3枚＝352分、娘々聖水LV10＋鏡＝272分）。初めて撃つカードは説明文の分数で見込みます。
    • 🎯 指名回復：ラベルを選んで 📖 中身を読む を押すと、実物のスキルをスキルレベルの高い順に並べます。回復させたいスキルに☑を付け、本数を決めて 🎯 開始。時間の制限はありません。☑なしのスキルは、枠が余れば一緒に載せます。本数はスキルの本数で数えます（1枚のカードが3つのスキルを持っていれば3本）。デッキにまだ空きがあれば、選んでいないラベルの回復中のカードも残り時間の短い順についでに載せます（神医の術式のカードも含む。HP が100に足りないカードと、無限回復のラベルのカードは載せません・v8.96〜）。終わる条件は指名したスキルだけです。1周ごとに、指名したスキルがデッキの上で回復したかを確かめ、済んでいれば施術を撃つ側のカードの回復は追わずに終えます（v8.97〜）。
  3. ③手で載せる・戻す：自動で回さず、手で 📥 デッキに載せる／📤 載せたカードを戻す こともできます（⚠ カードが動きます）。
  4. 押し方（v8.82〜）：♾ 開始・📥 デッキに載せる・📤 載せたカードを戻す・💊 神医の試し撃ち は二度押しです。1回目でボタンが「本当に実行?→8秒以内にもう一度」に変わり、8秒以内にもう一度押すと始まります。ブラウザの「よろしいですか？」の確認は出ません（外出先から Claude に頼んで動かせるようにするため）。終わったときのお知らせも画面の中に出ます。

動きの決まり

  • 回復させたいスキルを、回復させるために撃つことはしません。撃つたびに自分が回復中に戻って終わらなくなるのを防ぎます。
  • HPが100未満のカードは、先に神医の術式でHPを回復してから載せます。術式を撃つには、その拠点の内政官の席とデッキ枠のコストの両方が空いている必要があります。ツールがその拠点を選びます。術式が1枚も効かないときは、施術を撃たずにその回を止めて知らせます。
  • カードを降ろすのは、ファイルに対象のカードが残っていないときだけです。残っていればデッキに載せたまま続けます。
  • ツールが載せた記録のあるカードだけを降ろします。手で載せたカード・元から警護にあったカードには触りません。ただし、初期設定で「無限回復(施術)」に選んだラベルのカードは、手で載せたものでも完了したときに降ろします。次に ♾ を使うときは、施術のカードをもう一度載せてください。
  • 施術を撃つときは、作業拠点の内政官を（ツールが置いたものでなくても）外します。外した内政官は戻しません（ログに出ます）。
  • 貴重な施術（湯薬・継承のあるもの）は、撃てる残りが「残す枚数」になったら使いません。施術がそれしか無いときは「撃てるカードがありません」で止まります。
  • 途中でリロードや画面の移動があっても、次の読み込みで続きから進め、最後に後片付け（降ろす）をします。完了の報告もページをまたいで出ます（v8.48）。
  • ■ 停止は「中断」です。停止したら、次に開始を押すまで一切動きません（後片付けもしません）。デッキに残ったカードは手で降ろしてください（残ったカードはログに出ます）。
  • 🎯 は「無限回復」ラベルのカード（施術を撃つ側）には触りません。

🔁 奮迅連打（v8.84〜）

強襲天奮迅のような「出兵→戦闘不能→回復」をくり返すときの手間をまとめます。出兵のボタンは毎回自分で押します（押すたびに1回）。前後のデッキの入れ替えと回復はツールがやります。

  1. ①登録：連打する武将を出兵拠点の通常デッキに載せてから、出兵拠点を選び 武将取得 → 連打する武将に☑（1枚でも複数でも）。目的地はゲームの 簡易出兵先 に登録した名前を選ぶか、目的地を地図で指定 → 地図のマスを1回クリックすると入力・保存されます（v8.87〜）。取り消すときは同じボタンを再押しするか Esc。座標の手入力もできます。簡易出兵先はゲームの「編集」から登録・変更し、🔁 は画面の一覧を読み取ります。回数の目安、無限回復の一括UPの番号（本拠地枠／拠点+枠とその拠点）を入れます。
  2. ②準備（二度押し）：先に各拠点にカードを載せておきます（奮迅のカードも、速さを上げるカードも）。押すと、全部の拠点の通常デッキ・警護デッキの構成をそのまま記憶します。何も降ろしません（v8.92〜）。登録した武将が出兵拠点の通常デッキに無ければ載せてから記憶します。デッキを組み替えたら、もう一度押して記憶し直します。🃏 自動で入れ替える・👁 近くの新しい君主を囲む は止めます（元に戻すときに再開）。
  3. ③出兵（二度押し）：登録した武将を1枚ずつ、目的地へ強襲（奮迅のスキルつき）で出します。押すたびに1回です。
  4. ④回復：部隊が戻るのを待ち、全部の拠点のカードを降ろしてから、通常デッキに無限回復の一括UPを載せ、♾（10時間以上のスキルも対象）で回します。HP は神医の術式で100に戻し、奮迅の武将は警護デッキで回復します。回復したら、通常・警護とも全部降ろして、②準備で記憶した構成に載せ直します（速さのカードも元の場所へ・v8.92〜）。登録した武将が使えるかどうかを表示します。→ ③へ。②準備の記憶が無いときは始めません。
  5. 元のデッキに戻す（二度押し）：回数が終わったら／やめるときに。全部降ろして、記憶した構成を同じ場所に戻します。

⚔ 攻撃の構成（v8.98〜・奮迅の記憶とは別）

  • 今の構成を記憶（二度押し）：攻撃のデッキを組み、勅令などは内政にセットしてスキルを使ったあとで押します。全部の拠点の通常・警護のカードと、内政に座っているカードとそのスキル（1つ目のスキル）を覚えます。1回前の記憶は控えに残します。
  • 記憶した構成でセット（二度押し）：いま内政に座っているカードを外し、全部の拠点のカードを降ろしてから、覚えた構成に載せ直します。内政のカードは、元の拠点に載せて内政にセットし、スキルを使うところまで1回でやります。
  • 勅令のスキルがまだ回復中だと内政にセットできないことがあります。そのカードは置くだけで載せ、ログに名前を出します。

⚔ 攻撃連打（攻撃のあとの回復・v9.02〜）

攻撃の武将で攻撃したあとの「兵の補充 → 回復 → 攻撃の構成に戻す」を、ボタン1つでツールが最後まで進めます。出兵は手で行います。

  1. 攻撃の構成を記憶：攻撃の武将・置くだけのカード（王威令・王駿令など）・内政で使うカード（勅令など）を各拠点に載せ、勅令などは内政にセットしてスキルを使った完成形で、⚔ の 今の構成を記憶 を押します。
  2. 無限回復の構成を記憶：無限回復のデッキを組んで ♾ の 今の構成を記憶 を押します（無ければ 🔁 の一括UPの番号で載せます）。
  3. 兵を作るカードを記憶：兵を作るカード（例：重装槍兵修練）を、出兵する拠点で内政にセットした状態で 🪖 の 兵を作るカードを記憶 を押します。続けて 兵舎を読む → 兵舎と兵の種類を選びます。数は作れる上限までです。
  4. 🏃 出兵用（速度）の構成（v9.05〜）：遠くへ出すときは、全速令などを載せた形を一度作って 🏃 の 今の構成を記憶 を押します。記憶しておくと「攻撃のあとの回復」の最後はこの形に戻り、内政のスキル（勅令など）はまだ使いません。手で出兵したら、⚔ の 記憶した構成でセット で攻撃の構成と内政のスキルに切り替えます（入れ替えに約1分）。記憶が無いときは今までどおり攻撃の構成に戻ります。
  5. 🏪 足りない資源を市場で替えてから作る（v9.03〜・最初からオン）：兵を作る直前に、兵舎の画面に出ているその兵の必要な資源（槍兵なら木・石・糧、騎兵なら石・鉄・糧など）を読み、作れる数がいちばん増えるように、余っている資源を市場で足りない資源に替えます。残す量（最初は1億）より下には売りません。糧は兵が食べるので、残す量の2倍を残します。市場は「兵舎を読む」のときに一緒に探します。相場が60%なら、売った量の6割が手に入ります。
  6. 出兵：手で出兵します。
  7. 攻撃のあとの回復（二度押し）：①兵の補充（出兵する拠点の内政の席を空け、兵を作るカードを内政にセットしてスキルを使い、兵を上限まで作る）②内政を外して全部降ろす ③無限回復を載せる ④攻撃の構成のカードと兵を作るカードのうち回復中のものを、HP を戻してからまとめて回復（回復したら止まる）⑤攻撃の構成に戻す（内政のセットとスキル使用も）。途中でページが変わっても続きから進めます。

♾ 無限回復の構成（v9.00〜）

  • 無限回復のデッキを組んだら 今の構成を記憶（二度押し）を押します。カードを1枚ずつ、拠点と通常・警護まで覚えます。
  • ④回復 は、この記憶があれば一括UPのグループではなく記憶どおりに載せます。内政に座ったままのカードも先に外して降ろすので、予定したデッキが全部載ります。どの拠点の枠が30コストかも気にしなくて済みます。記憶が無いときは今までどおり一括UPのグループで載せます。
  • 記憶した構成でセット（二度押し）で、無限回復のデッキだけを載せることもできます（全部の拠点のカードを降ろしてから載せます）。

無限回復のカードはどこから載るか（一括UPのグループ）

④回復で載せる無限回復のカードは、ゲームの「デッキ一括UP設定」のグループから載せます。ツールは手で載せたカードを覚えているわけではありません。グループの中身を変えれば、次からそのとおりに載ります。

  • 番号の調べ方：ゲームの デッキ一括UP設定 を開き、「グループ選択」で自分の無限回復のグループを選びます。そのときのグループの番号（並び順の番号。例：21）が、🔁 の「無限回復の一括UP」に入れる番号です。グループの名前は何でも構いません。
  • 入れ方：グループが1つなら、本拠地枠か拠点+枠のどちらかに番号を1つ。2つ以上なら「21,22」のように並べます。グループの並びを変えると番号もずれるので、そのときは入れ直してください。
  • どちらの枠が30コストか：軍議所の「伍」の役割で決まります（長＝本拠地と塔が30、それ以外＝本拠地・塔以外が30）。デッキの画面の上の「◯/25」「◯/30」で確かめられます。
  • おすすめの組み方（代表の例）：無限回復1・2（1群・2群）を合わせて30コスト以内に組んで30の枠へ、無限回復3（3群）を25コスト以内に組んで25の枠へ。30の枠に内政官がいて1群・2群が入りきらないときは、25の枠を先に載せます（④回復は本拠地枠から先に載せます）。
  • 拠点+枠の拠点：🔁 の「拠点+枠←」の右の拠点を選びます。その拠点の通常デッキに空きが無いと載りません（④回復の前に空けておきます）。

回復の終了条件と注意（v8.89〜）

  • ④回復の ♾ は、開始時に登録していた武将のスキルが回復したら終了します。使用した施術の待ち時間は終了条件に加えません。回復対象の指定はページの再読み込み後も引き継ぎます。一括UPで載った通常デッキのカードも後片付けの対象として記録します。中断・読み取り失敗や、武将を戻せなかった場合は「完了」と表示しません（2026-10-15 実機で確認済み）。
  • 撃つ順番（v8.90〜）：④回復の ♾ は、拠点に関係なく短縮の大きい施術から撃ちます（必要な残り時間を超えない中でいちばん大きいもの）。別の拠点の施術を撃つときは、その拠点へ移ってから撃ちます。貴重な施術（湯薬・継承持ち）も温存せずに使います。そのため、直後の普段の ♾ や次の連打では、大きい施術が回復待ちになっていることがあります。普段の ♾ は今までどおり（1拠点を使い切ってから次へ・貴重な施術は設定の枚数を残す）です。
  • 速くする工夫（v8.93〜）：残りを1回で終わらせられる施術があれば、その中でいちばん小さいものを撃ちます（残り48分で20分の吐息を3回撃つより、80分の施術を1回）。術式で HP を戻したあとは、いちばん足りないカードが100と読めれば全カードの読み直しを省きます。登録した武将がデッキで回復済みと読めたら、終わりの確認の読み直しも省きます。
  • タブを触っても止まりません（v8.97〜）：④回復の途中でページを移ったり読み込み直したりしても、次にゲームのページを開いたときに続きから進めます。全部降ろす・無限回復を載せるの途中なら準備からやり直し、♾ の途中なら続きから、記憶した構成に戻すの途中なら戻す作業をやり直します。■ 停止を押したときは続きをしません。
  • ②準備は、押すたびに全部の拠点のデッキ構成を記憶し直します（v8.92〜）。デッキにカードが1枚も無いときは記憶しません。降ろせないカード（内政中など）は載ったまま回復し、戻すときもそのままにします。HP が足りないなどで載らなかったカードは、ログに名前が出ます。
  • HP の回復は ♾ の中で神医の術式を使います（戦闘不能の武将は HP が 100 になるまで載せられないため）。

出兵を自動でくり返す機能ではありません。普段の ♾ の動きは今までどおりです。

🏴 鹵獲

①A ②B ③開始 ④リングとの入れ替え

空き地へ武将を出して資源を持ち帰り、帰還したら自動で再出兵する機能。A・Bの2系統を別々の拠点・武将で同時に回せます（A＝本拠地/塔、B＝その他の拠点）。めくりと並行して動かせます。

  1. ①A／②B：拠点を選び 武将取得 → 使う武将に ☑。鹵獲先を追加 を押して地図の空き地をクリック（複数可）。
  2. ③時間と開始（ツールの鹵獲）：時間(分/最大60) を決め、繰り返すなら 周回 に☑。鹵獲開始(A+B) でA・Bまとめて開始。残り時間と獲得資源（今回／累計）が出ます。止めるときは ■鹵獲停止。
  • 周回：☑のときだけ、帰還ごとに繰り返します（v8.49 からチェックどおり）。☑なしなら1巡で終わります。
  • 本日の上限（既定90・最大100）：ゲームの鹵獲は1日100回まで（毎朝5:00にリセット）。設定した回数に達すると自動で止まります。ゲームの「鹵獲出兵制限中」も検知して止まります。
  • 出兵の余裕(秒)（⚙・既定10）：再出兵の間隔に足す余裕（乱数）。
上限60分長時間の連続出兵はリスクが高いため、1回の鹵獲は最大60分にしています。続けたいときは様子を見て再開してください。

④ 🃏 おまかせ自動鹵獲 ⇄ リングの入れ替え（v8.58〜・v8.62 から一括UPのグループで）

ゲームのおまかせ自動鹵獲とリングを、リングの予定に合わせて自動で入れ替えます（鹵獲はツールの鹵獲ではなく、ゲームの自動鹵獲を使います）。v8.62 からは、ゲームの「デッキ一括UP」のグループをそのまま載せます。グループの中は優先順位の高い順で、入る分だけ載ります（ツールはカードを選びません）。グループの中身を変えれば、そのまま入れ替えに反映されます。

  1. ＋構成を追加 で構成を2つ作る。1つ目＝鹵獲用、2つ目＝リング用。それぞれ拠点を2つまで選びます（例：拠点1＝本拠地/塔、拠点2＝もう1つの拠点）。
  2. 拠点ごとに 一括UP の欄へ、ゲームの一括UPのグループ番号を入れる（例：鹵獲用＝15「鹵獲 30」→本拠地、16「鹵獲 25」→もう1つの拠点（どちらの枠が30かは軍議所の「伍」の役割で決まる。伍長なら本拠地と塔が30、それ以外の役割なら本拠地・塔以外が30）／リング用＝13「ドリル 前線」→本拠地、14「ドリル 後方」→もう1つの拠点）。番号の横にグループ名が出ます。
  3. 自動鹵獲ON：チェックした拠点は、一括UPのときに自動鹵獲ONで載せます（既定：鹵獲用＝ON、リング用＝OFF）。
  4. おまかせ自動鹵獲の出兵先を、鹵獲を出す拠点ごとにゲームの「おまかせ自動鹵獲」画面で登録しておく（登録が無い拠点は、旧自動鹵獲の設定で出ます）。
  5. 自動で入れ替える をON。今すぐ適用 で手動でも入れ替えられます。
  • リングの5分前（破棄して回すリングの取り直し・内リングの発火・朝の取り直しなど。持ち続けるリングは対象外）に、鹵獲用の拠点の自動鹵獲ONのカードをOFFにします。
  • 部隊が全部戻ったら（部隊の一覧で確かめます。最大5分待ちます）、リング用に入れ替えます（v8.70）。順番は「対象の拠点のカードを一括で降ろす → 破棄して回すリングが動いていれば、先に領地統制を置く → ドリルのグループを一括UP」。
    領地統制を先に置くのは、ドリルを先に一括UPするとデッキコストが上限まで埋まり、領地統制の入る枠が無くなるからです。領地統制はもう1つの拠点（拠点2）の側から先に試します。
  • 一括UPのあとデッキコストが上限まで埋まらなければ、体力が100に足りないカードがある見込みなので、神医の術式で回復してから同じグループを1回だけ入れ直します（どのカードが足りないかはグループから読めないので、満タンぶんで術式を使います）。それでも埋まらなければ、ログに残りのコストを出します。入れ直しても増えなかったときは、そのグループ・その拠点では「そこまでが満杯」と覚え、次からは術式を使いません（v8.66。グループの次のカードが残りのコストに入らないだけのことがあるため）。
  • 破棄して回すリングに「破棄できていない自分の領地」が残っていて、領地統制が切れているときも、リングの出番とみなしてリング用に入れ替え、先に領地統制を置いて破棄させます（v8.70・日中の6:10〜21:35だけ）。
  • リングの出番が終わり、次の出番が15分以上先になったら、鹵獲用に戻します（自動鹵獲ONで載せ、おまかせ自動鹵獲が回り出します）。リングに取れる空き地が残っている間は、最大15分まで戻さずに待ちます（v8.67）。
  • 内政セット済のカード（領地統制など）と、動いているめくりの武将は降ろしません。そのぶんコストが減ります。
  • 降ろすカードの体力不足を構成ごとに覚え、次にその構成を載せる前に神医の術式で回復します（体力100未満のカードは一括UPで飛ばされ、下のカードが代わりに載ってしまうため。v8.74）。
  • 自動鹵獲の ON/OFF は、ゲームの画面で一度手で切り替えると、ツールがそのカードの設定を覚え、次から載せるたびにそのとおりにします（拠点に残すカードを OFF にしておく。v8.74）。
  • 領地統制などの内政官は、デッキコストの上限が30の方の枠から先に置きます（どちらが30かは軍議所の伍の役割で決まる。v8.74）。
  • 領地統制は、次のリングが作動する時間までスキルが残っていれば置いておき、作動前に切れるなら降ろします（v8.63）。鹵獲用に入れ替えるとき、一括UPの前に確かめます（「残っている」＝次のリングまで＋1周分の5分。動いている破棄して回すリングが無ければ降ろします）。降ろすと空いたコストに鹵獲のグループが入り、次のリングの前には、ドリルより先に新しい領地統制を置きます。
  • 一括UPの番号を入れていない構成は、前の方式（「今のデッキを記憶」したカードを1枚ずつ載せる）のまま動きます。
  • デッキパネルの上の文字で、今「鹵獲中／帰りを待っています／リング用」のどれか、次のリングまで何分かが分かります。

💰 自動寄付（⚙ の中）

倉庫が満杯に近づくと、超えた分の資源を自動で同盟に寄付します。倉庫が溢れると資源は軍費に流れ、軍費まで満杯だと鹵獲した資源がまるごと無駄になるので、その手前で倉庫を空けておく機能です。

  • 発動: 倉庫上限の◯%超（既定95）を超えた資源だけを、寄付後: ◯%まで（既定80）下げる分だけ寄付します。
  • 寄付は「サーバーのアクティブ拠点」から引かれます。判定と寄付額はサーバーの実際の在庫で計算します。在庫や倉庫上限が読めないときは寄付しません。
  • 🔎 在庫を確認 で資源と倉庫上限を読みます（寄付はしません）。

⚔ 軍費→突撃ポイント（⚙ の中・v8.57）

軍費が上限まで貯まると鹵獲が止まります。軍費が満タンになったら100万ぶんだけ突撃ポイントへ をONにすると、5分ごとに軍議所の軍費を見て、満タンのときだけ軍費100万ぶん（1回＝軍費2万で突撃ポイント+5 を50回）をNPC領地突撃ポイントに換えます。満タンでなければ何もしません。休戦明けの戦いに軍費を残すため、全部は換えません。突撃ポイントが上限（10,000）に近づくとログで知らせます。換えたあとは軍費が減ったかを読み直して確かめ、減っていなければ30分止めます。

施設削除と拠点を分け合う（v8.56）ゲームの「今の拠点」は1つしかないので、ルート捲りと施設削除は、拠点を切り替えて送る数秒だけ使用権を持ち、すぐ返します。リングなどのルート捲りが優先です。施設削除のパネルを開いていても、鹵獲・リングは止まりません（施設削除が v0.24 以前のときだけは、今までどおりパネルを開いている間は止まります）。

⭕ リング

①場所 ②武将 ③やり方 ④開始

中心の周りを一周するマス（輪）を取り、保護が切れる前に取り直して、囲いを守り続ける機能です。リングの本体は「外へ広げること」で、内側の輪は保険です。

手順

  1. ①輪の場所：中心を地図で指定 を押して守りたい拠点のマスをクリック（または座標を入力）。距離＝中心から何マス目か（1〜15）。輪を地図に描く で、輪が地図に緑で出ます（めくりの経由地は青。v8.60 から別々の一覧です。リングの輪を描いても、めくりのルートは変わりません）。上限の15を超える数を入れると、知らせて何も変えません。
  2. ②出す武将：拠点を選び 武将取得 → 使う武将に ☑（リング専用。めくりの☑とは別）。
  3. ③やり方：パターンを選ぶ。
    • A 単リング：輪を1つだけ扱う単発のリングです（v8.77）。輪のマスを全部取り終えたら（「破棄して回す」がONなら、全部に破棄をかけ終えたら）自動で終わり、取り直しはしません。取れなかったマスがあれば、名前を出して終えます。人に取られたマスを攻撃しに行くこともしません。
    • B 多重外→内：いちばん外の輪が防衛線、その1つ内が保険です（v8.80 から2列まで。それより内側は作りません）。保険は、防衛線の保護が切れる30分前に、防衛線の空き地から外へ辿って敵の領地に届く経路があるときだけ取ります（外側が安全なら作りません）。作動状況に「役割: 防衛線＝距離◯／保険＝距離◯」と出ます。外へ出ます（v8.81）：日中、防衛線が距離5未満なら1つ外の輪を見張り、空き地は取る、敵の領地は保護が切れた瞬間に捲る、味方の領地で保護が切れているものは同盟を脱退して捲る（奪取のあいだこのリングは一時停止し、再加入後に続きから）。自分・味方の領地の破棄完了・保護切れが30分以内なら、先に保険を取ってから外が空くのを待ちます。外の輪を取り切ると防衛線が1つ外へ移り、前の防衛線は保険に、前の保険は掃除（破棄して取り直さない）になります。上限は距離5です。
    • C 多重内→外：外が敵や味方で埋まって外から囲めないとき、内側を先に確保してから外へ広げます。
    • E 敵リング：敵の輪を、保護が切れた瞬間に奪います。単発です（v8.79）。全部捲り終えたら終わり、捲った領地は持ち続けます（破棄も取り直しもしません）。E の欄の「捲り終えたら自リング維持(B)に移る」をONにしたときだけ、捲り終えたあとに自リング維持へ移ります（「破棄して回す」の設定に従います）。
    距離の詳細 は距離を変えると自動で更新されます（B・Cは内へ展開。例 3→「3,2,1」）。飛ばしたいときだけ手で直します。
  4. 取ったあと：
    • 破棄して回す（既定ON）：取得→破棄→取り直し、を繰り返して保護を保ちます。
    • 持ち続ける：破棄せず置いておきます（足場用）。

動きの決まり

  • 輪のマスは、自分か味方の領地に隣接しているマスから順に取ります。取れたマスが次の足場になります。どこにもつながらないマスは保留して、足場が伸びたら取ります。
  • 敵やNPCのマスも、保護中でなければ捲ります。味方のマスは取りません（同盟・味方マス参照）。
  • 破棄は日中に行います。夜は、破棄が停戦（毎晩1:00〜6:10）に食い込む時間から新しい破棄をやめて保持に切り替えます（距離3以下は22:00、距離4以上は0:00が締め切り）。停戦中は通信を止め、朝に再開します。
  • 予定外に空いたマスもすぐ取り直します。リロードしても続きから動きます。
味方の領地を足場にするとき味方の領地には手を付けず、その隣の空き地を取れば自分の足場になります。そのときはなるべく外側の味方の領地から足場を作ってください。内側の味方の領地を足場にすると、その足場と伸ばした領地が、あとで内側に輪を積むときに破棄が間に合わず、輪が間に合わなくなるおそれがあります。

⏰ 予約

すでに持っている外の輪（中心＋距離）の内側を、保護が切れるのに合わせて自動で積んでいく機能です。中心と距離に持っている外の輪を入れ、リング用の武将に☑を入れて ⏰ 予約開始。ツールが外の輪の保護の残りを測り、いちばん早く切れるマスの隣から取り始めます。1周取り終えると、次の内側を自動で予約します。解除は同じボタン、または ■全停止・🗑全リセット・🔔リセット合図。

武将の排他ルール

重要

同じ武将は同時に2つの用途では使えません（1体は1回しか出兵できないため）。ロックは実行中だけかかります。止めている間は☑を自由に付け替えできます。

  • 鹵獲やリングで使用中の武将は、めくりのリストで 🔒 が付き選べません。
  • めくり・番人・鹵獲A/B・リングは同時に動かせます。それぞれ別の武将を割り当ててください（同じ武将だと帰還待ちで交互に待たされます）。
  • ツールは出兵を1件ずつ順番に送るので、出兵元の拠点を取り違えることはありません。
確認武将の選択は出兵に直結します。長く回す前に、少量で「意図した武将・拠点で出るか」を確かめてください。

複数のパソコンで使うとき

  • 設定はパソコンごと（ブラウザごと）に保存されます。会社で設定した輪や☑は、自宅のパソコンには来ません。別のパソコンでは設定を入れ直してください。
  • 動いているものも、そのパソコンでしか動きません。ツールはゲームのページを開いている間だけ動きます。ページを閉じると、そのパソコンのめくり・リング・鹵獲などは止まります（取った領地や出兵中の部隊はゲームのサーバー側にあるので、そのまま残ります）。再び開けば、止まっていた輪は自動で再開します。
  • 同じアカウントのゲームを、2か所で同時に動かさないでください。ツールは出兵や寄付のたびにゲームの「今の拠点」を切り替えるので、2か所が拠点を切り替え合うと、思わぬ拠点から出兵や寄付をすることがあります。
  • 別の端末から止めたいときは、🔔 本拠地名リセット合図 を使います。
  • 夜も止まらないように、パソコンのスリープを切り、Chrome のメモリセーバーでゲームのサイト（w◯.3gokushi.jp）を「常にアクティブ」に登録してください（またはメモリセーバーを切る）。タブの最小化・画面のロックは大丈夫です（v8.55）。

🧱 施設削除（別ツール）

v0.25

拠点の施設を「残す数／壊す数」で指定して削除するツール。都市画面の拠点名の横に出る [施設削除] を押すとパネルが開きます（全体地図など都市以外では出ません）。

  1. 都市画面で [施設削除] をクリック。パネルに 対象拠点: (座標) が常に表示されます。
  2. 壊す施設にチェックを入れて 保存 を押す（勝手には保存されません。保存はチェックした施設だけ・拠点ごと）。
  3. 自動巡回を開始。削除はタイマー式で1拠点ずつ順番に進みます（1件あたり数十分〜1時間）。削除の時刻が来ると、施設削除が自分で対象拠点に切り替えて次を始めます（v0.25）。対象拠点の画面を開いておく必要はありません。
  • 既定はすべて「残す」。拠点を空にするには 6種以外を全部壊す（大宿舎・遠征訓練所・兵器工房・練兵所・見張り台・宿舎は残る）。チェック全解除 で全部「残す」に戻せます。
  • 保存したあとで施設の数が変わった場合、その施設は自動でチェックせず「⚠数が変わっています」と警告だけ出します。
  • 拠点の座標が一つに決まらない画面（全体地図など）では、保存も削除もしません。
  • 編集中のチェックは自動で下書き保存され、リロードしても同じ拠点・同じ施設数なら復元されます。
  • 削除の直前に毎回サーバーの現在拠点を確かめ、対象拠点と一致したときだけ削除します（自分で切り替えたあとも同じ）。
  • ルート捲りとは拠点の使用権を分け合い、ルート捲り（リングなど）が優先です（v0.25）。ルート捲りと施設削除は両方を新しい版にしてください。ルート捲りが v8.55 以前のときは、今までどおり対象拠点を表示している間だけ削除します。
併用注意オートビルダーの自動削除と同時に動かすと施設を取り合うので、削除を動かすのはどちらか片方だけにしてください。
夜間の無人運用は非推奨建物の削除は取り消せません。目の前で1拠点ずつ進めるのが安全です。
